# Wedding website

A simple static wedding website, ready for GitHub Pages.

## Preview locally

1. Open a terminal in this folder.
2. Run `npm run dev`.
3. Visit [http://localhost:4173](http://localhost:4173).
4. Press `Control-C` in the terminal when you are finished.

No dependency installation is required.

## Check the site

Run `npm run check` before committing changes.

## Publishing

Pushing the `main` branch starts the included GitHub Pages workflow. The first
time, the repository may need **Settings → Pages → Source → GitHub Actions**
selected on GitHub.
